# Perpetual Mission Engine (PME)

## Concept
PME is a forever-running mission generator driven by **group agendas**.
It is not level-based “quest content.”
It is a system that pushes the universe forward.

## Group Goals
Each group (race collective, faction, religion, pirates, etc.) has:
- Long-term objectives (control, survival, discovery, conquest, preservation)
- Resource needs and pressure points
- Rivalries and alliances

## Mission Generation
Missions are produced to advance goals:
- Delivery / transport
- Retrieval (relics, resources, intel)
- Escort / protection
- Sabotage / disruption
- Discovery / scouting
- Vault access attempts
- Political influence actions

## World Impact
Completing missions:
- Shifts faction power
- Changes settlement growth/decay
- Unlocks/locks future missions
- Alters local hostility and safety
- Writes history into the persistent world state

## Pirate Interference
Pirate events can interrupt:
- Errands/delivery missions
- Story path missions
Player can:
- Fight
- Flee
- Aid pirates (joining overlays/factions)
