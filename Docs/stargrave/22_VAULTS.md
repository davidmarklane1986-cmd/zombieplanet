# Vaults

## Definition
Vaults are fixed locations that function as **tests**, not standard dungeons.
They are tied to:
- Race philosophies
- Player paths
- Relic understanding

## Vault Content Types
- Environmental puzzles
- Echo dialogues / memory scenes
- Relic trials
- Moral/choice locks with consequences

## Vault Outcomes
Vaults can:
- Accept the player (grant progress/reward)
- Reject the player (deny or redirect)
- Offer alternative outcomes based on inferred alignment
- Record outcomes into world state

## Hinting Toggle (Testing Feature)
- Vaults can optionally hint at other paths if alignment does not match.
- This behavior is toggleable via an in-game option (for testing both experiences).
