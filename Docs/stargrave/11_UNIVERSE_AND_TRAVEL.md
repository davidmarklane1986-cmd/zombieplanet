# Universe & Travel

## Universe Model
- Single shard, shared evolving world state.
- ~500–1000 static stars (design range).
- Stars have fixed positions and remain visible at all times (sky + space).
- Manual travel between stars is possible.

## Star Systems
Each star system may contain:
- Planets (0–N)
- Moons (0–N)
- Debris fields / orbital points of interest
- Fixed locations that persist (vaults, relic sites, libraries, major settlements)

## Warp Travel Rules
Warp travel exists to manage distance, but it must obey:
- Warp is traversal, not teleport.
- Player can cancel warp at any time.
- Player can exit mid-route and appear somewhere between start and destination.
- No loading screens between stars as a requirement of travel.

## Persistence Rules
- Stars/systems are generated once and saved permanently (see Build World Once).
- Locations (vaults, true relic sites, libraries) are fixed in world coordinates.
