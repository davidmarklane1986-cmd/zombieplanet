# Glossary (Canon Terms)

- **BWO (Build World Once):** The rule/system that generates universe layout once and persists it.
- **Cube-sphere:** A planet mesh built from six cube faces inflated into a sphere.
- **True Relic Site:** Fixed canonical location of a relic in the shared universe.
- **Shadow Copy:** A non-canonical duplicate of a relic site used for pacing or misdirection.
- **Vault:** Fixed philosophical “test” location tied to race/path.
- **PME (Perpetual Mission Engine):** System generating endless missions from group agendas.
- **Paths:** Listener, Echoforger, Gravetaker, Witness, Bound One — inferred alignment categories.
- **Grand Authors:** Five silent nomads at start/end; un-interactable; reflect path progress.
- **Single shard:** One shared world state for all MMO players; no instancing.
